Mẫu và cấu hình nâng cao

Dán mảng JSON chứa id/notifyId, notifyNo và context từ search để tái sử dụng mẫu; để trống để tìm theo ngày. Một tập mẫu được lặp lại trong mỗi giai đoạn.

Khoảng cách 0 = không giãn cách request. Ngân sách request 0 = không giới hạn. 401/403 luôn dừng; ngưỡng lỗi và dừng khi gặp 429 chỉnh ở trên. Retry vẫn theo Retry-After/backoff. Request đang gửi có thể hoàn tất sau khi bấm dừng hoặc đạt ngân sách.
